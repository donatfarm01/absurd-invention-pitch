Entry for the make.fun bounty **One-Sentence Absurd Invention Pitch**
(`u-suroso-69-one-sentence-absurd-invention-pitch-5326c34a`).

The program writes one sentence pitching a ridiculous invention that fixes
a tiny everyday annoyance, to `/output/entry.txt`:

> A smoke alarm that whispers 'relax, it's only toast' instead of
> shrieking, so burnt breakfast stops sounding like the house is on fire.

Pure Python standard library, no network, deterministic: the same 135
characters on every run.
